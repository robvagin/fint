FINTукраинская кириллица из деталей самого шрифта

Перетащи сюда .ttf или .otf с латиницей или нажми «Подобрать шрифт»: страница сама найдёт на Маке шрифты без кириллицы. Всё считается в этой вкладке, ничего никуда не уходит

  1. Характер: штамб, перекладина, тонкая и толстая диагональ, ось, засечки, кончики
  2. Сборка: каждая буква из деталей, цвет показывает донора, контур уже вычищен
  3. Шрифт целиком: набор украинским текстом, буквы на доводку подсвечены
  4. Набор для Illustrator: слева чистая буква для доводки, справа её детали. Готовое кидаешь обратно
